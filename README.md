A Telegram bot for tracking personal expenses and income, built as a learning project while I'm exploring software development.

## Features

- **Track expenses:** Record spending by category.
- **Track income:** Record money received.
- **Multiple currencies:** Support for USD and KHR.
- **Transaction categories:** Food, Transport, Shopping, Bills, Study, Entertainment, Health, and Other.
- **Financial reports:** View daily, weekly, and monthly summaries.
- **Transaction management:** View recent transactions and delete selected records with confirmation.
- **Telegram interface:** Interact with the bot through commands and inline buttons.

## Running the Project

This project uses Telegram Serverless tooling. The exact setup depends on the platform's current requirements.

1. Clone this repository.
2. Install the required dependencies.
3. Configure the required Telegram Serverless credentials and application settings.
4. Review the database schema and apply the required migration if setting up a new database.
5. Deploy using the configured `tgcloud` tooling.

Never commit your Telegram bot token, API keys, or other private credentials. Use the platform's secure configuration mechanism.
